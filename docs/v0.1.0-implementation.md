# v0.1.0 implementation

Goal: On a clean Ubuntu 24.04 x86_64 VPS, install an nginx webroot for HTTP-01
and a TLS listener bound only to 127.0.0.1:9443. Leave Docker, Remnawave,
Xray, ports 2222/8443 and the firewall untouched.

Decisions:

- `--check` is read-only. `--install` is explicit and fails if an existing
  nginx installation predates this installer.
- No automatic `full-upgrade` or reboot. Package installation is limited to
  nginx, certbot, openssl and ca-certificates; Ubuntu package dependencies
  are managed by apt.
- The state file retains DOMAIN, TARGET_PORT and VERSION. A separate
  installer-owned marker records that package installation began, so a
  retry after an interrupted apt run can distinguish its own attempt.
- Every managed file is compared with its expected content before reuse.
  Existing, different content stops the installer.
- The package-provided default nginx site can remain enabled. The managed
  HTTP server is selected by its exact domain name. No foreign site is removed.
- HTTP serves a neutral Welcome page and HTTP-01 challenge files.
- A pre-existing certificate lineage for a new installation is rejected.
  Certbot uses webroot and asks for a contact email. A valid certificate
  created during an earlier installer attempt is reused.
  A deploy hook reloads nginx after a successful renewal.
- HTTPS listens on 127.0.0.1:9443 only. Remnawave settings are printed for
  manual entry.
- `check.sh` makes no changes. `uninstall.sh` only removes files whose
  identity is confirmed; certificate deletion is opt-in.

Implementation order:

1. Correct incomplete-install status and documentation.
2. Add package-stage marker and resume checks; invoke package installation.
3. Create webroot, HTTP site and exact enabled link; validate nginx before
   starting/reloading it.
4. Issue or reuse certificate; validate SAN and expiry.
5. Create local HTTPS site and deploy hook; verify ports, TLS and renewal.
6. Add read-only checker, guarded uninstaller and release instructions.
7. Verify Bash syntax and helper behavior locally, then run integration
   checks on the Ubuntu VPS before a v0.1.0 release.
